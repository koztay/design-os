## Project Summary

**AccessiblePrague** empowers wheelchair users to navigate Prague's streets confidently with:

- **Interactive Map** — OpenStreetMap + Leaflet with accessible route calculation
- **Community Reporting** — Submit obstacles/improvements with photos and GPS
- **Admin Data Management** — Table view with import/export (GeoJSON/CSV)
- **Settings** — Language (Czech/English), mobility profile, visual accessibility

**Tech Stack (in components):**
- React with TypeScript
- Tailwind CSS v4
- lucide-react icons
- Leaflet for maps (to be integrated)
